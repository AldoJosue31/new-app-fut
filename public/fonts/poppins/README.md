# Poppins

Latin WOFF2 subsets for weights 400, 600 and 700, self-hosted for the password recovery screens through `next/font/local`.

Source: [Google Fonts](https://fonts.google.com/specimen/Poppins), retrieved on 2026-10-07. Copyright 2020 The Poppins Project Authors. Distributed under the [SIL Open Font License](./OFL.txt).

Original files:

- 400: https://fonts.gstatic.com/s/poppins/v24/pxiEyp8kv8JHgFVrJJfecg.woff2
- 600: https://fonts.gstatic.com/s/poppins/v24/pxiByp8kv8JHgFVrLEj6Z1xlFQ.woff2
- 700: https://fonts.gstatic.com/s/poppins/v24/pxiByp8kv8JHgFVrLCz7Z1xlFQ.woff2

The application-wide Poppins declaration remains as it was. These files are loaded only by the recovery card.
